## 동시에 돌리는 순서

1. **1차 (바로 동시에)**: JOB-9, JOB-10, JOB-12, JOB-14, JOB-15
2. **2차**: JOB-11 (9·10 뒤), JOB-13 (9·12 뒤), JOB-16 (15 뒤)
3. **3차**: JOB-17 (9·14·15 뒤)

게임 개발 순서가 3막 → 4막 → 5막이라 **3막용(JOB-9·10·11)을 먼저** 끝내면 바로 화면에 반영된다. 이미지가 없어도 게임은 임시 도형으로 돌아간다.
